04 / ACCESSIBILITY

Accessible by default

Use semantic HTML, visible focus, meaningful link text, sufficient contrast, readable line lengths, responsive layouts, and non-color-only status communication.

05 / PRIVACY

Collect less. Explain more.

Do not request personal data unless it is necessary for a clear product purpose. Keep future credentials server-side, never expose secrets in client code, and make sensitive choices understandable.
