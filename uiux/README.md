# HS/Design — UI/UX Portfolio

A separate UI/UX and product-design portfolio surface for Hanshit, intentionally kept isolated from the main CSE developer portfolio.

## Structure

- `index.html` — responsive portfolio landing page
- Selected work — Study Hub, Study Planner, Learning Dashboard
- UX process — Problem → Research → Users → IA → Flow → Wireframe → UI → Prototype → Test → Improve
- Practice areas — Figma, design systems, accessibility, privacy-conscious UX, usability testing, product thinking

## Design direction

The portfolio prioritizes evidence of design thinking over decorative presentation. Future case studies should document the problem, users, constraints, decisions, artifacts, testing evidence, iterations, and final outcome.

## Security and privacy

- No API keys, tokens, passwords, or credentials are stored in the frontend.
- No unnecessary personal contact data is embedded.
- Do not commit secrets to this directory.
- Keep any future API integration server-side and use environment variables for secrets.
- Minimize collection of personal data in portfolio/contact flows.
- Validate and sanitize any future user-controlled input.

## Future Figma work

The Figma version will be created separately when Figma access is available again, then used to formalize the design system, components, case-study templates, and prototype flows without changing the existing CSE portfolio.
