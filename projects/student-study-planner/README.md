# Student Study Planner — UX Prototype

A student-focused planning interface built from the UX foundation before Figma implementation.

## UX flow
Problem → Users → Goals → IA → User Flow → Wireframe → UI → Prototype → Test → Improve

## Prototype screens
- Dashboard
- Weekly Planner
- Focus Session

## Design principles
- Clear information hierarchy
- Responsive layout
- Keyboard-friendly interactions
- Visible states and feedback
- Privacy-conscious local-only demo data

## Live prototype
Open `index.html` from the project folder through GitHub Pages.

## Evidence status
This is an active learning prototype. Product assumptions are documented as hypotheses until user testing validates them.
