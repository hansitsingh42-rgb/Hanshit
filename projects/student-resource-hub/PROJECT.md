# Student Resource Hub

A modern academic resource discovery interface designed for students to find first-year study material by subject and chapter.

## Highlights

- Subject → chapter → resource organization
- Resource search and subject filters
- Resource detail and preview interface
- Save-for-later bookmarks
- Recently viewed and study progress state
- Responsive multi-page UI
- Premium glassmorphism visual system
- Animated aurora background and lightweight particle field
- Interactive 3D-style hero motion
- Dark/light theme support
- Keyboard shortcut: Ctrl/Cmd + K for search
- Reduced-motion support for accessibility

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- HTML5 Canvas
- LocalStorage
- GitHub Pages

## Important Note

The GitHub Pages version is the static portfolio/demo interface. Real authentication, OAuth, server-side resource management, database persistence and server-side contact handling belong to the separate full-stack Student Resource Hub application.
