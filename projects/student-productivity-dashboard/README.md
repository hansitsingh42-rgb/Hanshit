# Student Productivity Dashboard

A clean, responsive productivity dashboard designed for students.

## Features

- Add, complete and delete daily tasks
- Clear completed tasks
- Automatic task completion percentage
- 25-minute focus timer with reset
- Study-time counter
- Subject progress cards
- Dark/light theme
- Local storage so tasks and theme persist in the browser
- Responsive layout for desktop and mobile

## Tech Stack

HTML • CSS • JavaScript

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Project goal

Practice frontend development, DOM manipulation, browser storage, responsive UI design and basic productivity-app logic.
