# GitHub Profile README Setup

This repository contains the main Hanshit project portfolio.

## Profile README

GitHub displays a profile README only when a **public repository has exactly the same name as the GitHub username**.

For this account, the required repository is:

`hansitsingh42-rgb/hansitsingh42-rgb`

The connected GitHub integration currently does not expose a repository-creation endpoint, so that special repository cannot be created automatically from this connection.

Once the repository is created, copy the profile README content from the main `Hanshit` repository into its `README.md`.
