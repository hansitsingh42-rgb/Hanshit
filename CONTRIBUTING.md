# Contributing

Thanks for taking an interest in this repository.

## Before contributing

- Read the project README and the relevant project documentation.
- Keep changes focused and easy to review.
- Do not commit secrets, credentials, API keys, or personal data.
- Use clear file names and consistent formatting.

## Pull requests

A useful pull request should include:

1. What changed
2. Why the change was made
3. How it was tested
4. Any known limitations

For UI changes, include a short description of the affected screen or feature.

## Code quality

Prefer simple, readable solutions. Avoid unnecessary dependencies and keep documentation aligned with the actual project behavior.
