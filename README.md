A full-stack academic resource library organized around **Subject → Chapter → Resource**.

- **Problem:** make study material easier to discover and manage.
- **Stack:** Next.js, React, TypeScript, Prisma, PostgreSQL, Auth.js
- **Demo:** [Static preview](https://hansitsingh42-rgb.github.io/Hanshit/student-resource-hub/)
- **Source:** [`student-resource-hub/`](./student-resource-hub/)

- **Demo:** [Live preview](https://hansitsingh42-rgb.github.io/Hanshit/study-resource-manager/)
- **Source:** [`projects/study-resource-manager/`](./projects/study-resource-manager/)
- **Case study:** [`Study Resource Manager`](./docs/ui-ux/study-resource-manager-case-study.md)
- **Run:** open `projects/study-resource-manager/index.html` in a browser.
