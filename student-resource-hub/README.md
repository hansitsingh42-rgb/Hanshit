# Student Resource Hub

A new full-stack student resource library project. This project is intentionally isolated on the `project/student-resource-hub` branch so the existing `main` project remains unchanged.

## Current foundation

- Next.js App Router foundation
- Responsive professional UI
- Resource cards
- Accessible search field foundation
- Skeleton loading screens with shimmer effect
- Reduced-motion support
- Clear loading state

## Planned build

1. Subject → Chapter → Resource hierarchy
2. PostgreSQL database with Prisma
3. Secure authentication and role-based authorization
4. Admin dashboard for resource management
5. Search, filters and resource preview
6. Secure server-side validation and API boundaries
7. Error and empty states
8. Analytics for resource usage
9. Automated tests and production verification
10. Vercel deployment

## Development principle

Existing `main` content is not modified by this project. Changes are developed independently first and should only be merged deliberately after testing.
