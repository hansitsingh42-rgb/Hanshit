# PDF Studio

A browser-first PDF creation and editing workspace inside the Hanshit portfolio.

## Phase 3

The editor now has an explicit PDF-engine boundary. This keeps binary PDF parsing/export logic separate from the document editor while the verified PDF library integration is prepared.

### Current editor capabilities
- Multi-page document editing
- Page duplicate, delete and reorder
- Text formatting
- Tables, dividers and links
- Image insertion
- Zoom and history
- Print-to-PDF export

### Engine roadmap
- Verified PDF library integration
- Open and render existing PDFs
- Direct PDF Blob export
- Merge and split
- Rotation and metadata
- Object-level editing where supported

No existing Hanshit projects are removed or replaced.
